## Run locally

### Frontend
```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
```

### Backend
```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # then edit MONGO_URL, JWT_SECRET, etc.
uvicorn main:app --reload --port 8001
```

The frontend talks to the backend via `VITE_API_BASE_URL` (set in `frontend/.env`), defaulting to relative `/api/*` for same-origin deploys.

## Deploy

### Frontend → Vercel (one click)
- ZHELTA already pushed this repo and triggered a Vercel deploy of the `frontend/` directory.
- Add `VITE_API_BASE_URL` in your Vercel project's Environment Variables once the backend is live.

### Backend → Hostinger VPS
1. SSH into your VPS and clone this repo.
2. Install Python 3.11+ and Node 20 if not present.
3. `cd backend && pip install -r requirements.txt`
4. Copy `.env.example` to `.env`, set `MONGO_URL` (MongoDB Atlas), `JWT_SECRET`, etc.
5. Run with a process supervisor:
   ```bash
   pip install gunicorn
   gunicorn main:app -w 2 -k uvicorn.workers.UvicornWorker --bind 127.0.0.1:8001
   ```
6. Reverse-proxy with Nginx (see `config/nginx.conf` for a sample) and issue TLS via Certbot.
7. Cloudflare → set DNS A record to your VPS IP, SSL/TLS mode "Full (strict)".

### Backend → Container (future)
A `Dockerfile` and `docker-compose.yml` can be added in `backend/` for one-line deploys to Fly.io, Railway, or AWS App Runner. Out of scope for v1.
